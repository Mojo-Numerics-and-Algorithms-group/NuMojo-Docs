# NuMojo-Docs

Documentation and base for the documentation website for NuMojo
(https://numojo.readthedocs.io), checked out as a sibling of the
[NuMojo](https://github.com/Mojo-Numerics-and-Algorithms-group/NuMojo) repo:

```
Codes/
  NuMojo/
  NuMojo-Docs/
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install mkdocs mkdocs-material
```

## Preview the site locally

```bash
mkdocs serve -f docs/readthedocs/mkdocs.yml
```

## Regenerating the site from a NuMojo checkout

`docs.py` regenerates the API Reference, Getting Started, User Guide, and
Developer Guide pages, `mkdocs.yml`'s nav, and `stylesheets/extra.css` from
`docs.json` plus the NuMojo repo's own `README.MD` and `docs/`. Run it
after `docs.json` is up to date:

1. Regenerate `docs.json` from the current NuMojo source:
   ```bash
   python3 gen_docs_json.py ../NuMojo -o docs.json
   ```
   This runs `mojo doc` separately on each of `numojo/`'s top-level
   members (`__init__.mojo`, `prelude.mojo`, `core/`, `routines/`) and
   merges the results, instead of `mojo doc numojo/ -o docs.json` — the
   single whole-package invocation currently fails on a `mojo doc`
   cross-file type-resolution bug even though the real compiler builds
   the same code cleanly. See the docstring in `gen_docs_json.py` for
   details; update it if `numojo/`'s top-level layout changes.
2. Regenerate the site content:
   ```bash
   python3 docs.py
   ```

## Structure

* `docs.json` — merged `mojo doc` output (see `gen_docs_json.py`)
* `docs.py` — generates the API Reference, Getting Started/User
  Guide/Developer Guide pages, `mkdocs.yml`, and `extra.css` from
  `docs.json` and the NuMojo repo's `README.MD`/`docs/`
* `gen_docs_json.py` — regenerates `docs.json` from a NuMojo checkout,
  working around the `mojo doc` whole-package bug
* `docs/readthedocs/`
  * `mkdocs.yml` — site config (regenerated by `docs.py`)
  * `docs/` — site content (regenerated by `docs.py`; hand edits here are
    overwritten on the next run — edit the NuMojo repo's `README.MD`/
    `docs/` or `docs.py`'s templates instead)
    * `API reference/` — generated from `docs.json`
    * `getting_started/`, `user-guide/`, `developer-guide/` — generated
      from the NuMojo repo's `README.MD` and `docs/`
    * `index.md` — homepage (template lives in `docs.py`)

`.readthedocs.yaml` at the repo root configures the Read the Docs build.
